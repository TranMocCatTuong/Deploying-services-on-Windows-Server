# How to create new Group?

1. Open **Server Manager**, [1] select **Tools**, [2] choose **Active Directory Users and Computers**.

  ![ Image 1. ](/img/4_1.png)

2. Select OU (Organizational Unit) where you want to create the group.

  ![ Image 2. ](/img/4_2.png)

3. Select folder **Users**.

  ![ Image 3. ](/img/4_3.png)

4. Right-click in the empty space, [1] then select **New** and [2] choose **Group**.

  ![ Image 4. ](/img/4_4.png)

5. [1] Enter the **Group name**, [2] select the **Group scope**, [3] then choose the **Group type**. [4] Click **OK** to complete the creation of the group.

  ![ Image 5. ](/img/4_5.png)
