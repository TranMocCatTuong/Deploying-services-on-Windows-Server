# How to configure network?

1. Open **Settings** and select **Network & Internet**.

  ![ Image 1. ](/img/2_1.png)

2. [1] Select **Ethernet**, [2] double click **Change adapter options**.

  ![ Image 2. ](/img/2_2.png)

3. Double click **Ehernet0**.

  ![ Image 3. ](/img/2_3.png)

4. Select **Properties**.

  ![ Image 4. ](/img/2_4.png)

5. Select **Internet protocol version 4 (TCP/IP v4)**

  ![ Image 5. ](/img/2_5.png)

6. [1] Configure IP address and [2] DNS server address. [3] Then click **OK** to finish.

  ![ Image 6. ](/img/2_6.png)
